Uses "declarativeNetRequestWithHostAccess" only for short-lived session rules on supported unlock flows. On matching short-link hosts it adjusts response headers so the page’s unlock scripts cannot fight the flow, and when opening the destination it sets a Referer request header required by those hosts. Rules are tab-scoped or host-scoped, cleared when the tab closes or the hop finishes, and are not used to block ads, inject content, track browsing, or rewrite unrelated network traffic.
