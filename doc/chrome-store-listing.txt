Skip Wait helps you get past mandatory delays on supported link shorteners, safelinks, and file hosts. On matching pages it either sends you to the destination or finishes the unlock steps so you reach the final URL or download sooner. No account or paid plan is required. Other browsing is left alone.


--------------------------------------------------------------------------------
OVERVIEW
--------------------------------------------------------------------------------

Open a supported short link or delay page as usual. The extension detects the page type and completes the flow—often with an instant redirect, otherwise by finishing the on-page unlock steps. Unsupported sites are not changed.


--------------------------------------------------------------------------------
SUPPORTED BEHAVIOR
--------------------------------------------------------------------------------

• Short links and safelinks — follow the chain to the final URL when possible
• File hosts and download pages — automate countdown unlocks where supported
• Pages that delay access with timers or session checks — complete the supported unlock path
• New sites are added over time; use the popup to request support for a site we miss


--------------------------------------------------------------------------------
FEATURES
--------------------------------------------------------------------------------

• Runs automatically on supported pages — no site-by-site setup
• Popup for support requests (GitHub, email, or Telegram) — not a settings panel
• Free — no subscription, sign-up, or paywall
• No effect on pages outside supported short-link or delay flows


--------------------------------------------------------------------------------
HOW TO USE
--------------------------------------------------------------------------------

Install the extension and open any supported short link or delay page. The extension handles the rest. No configuration or account is required.


--------------------------------------------------------------------------------
SINGLE PURPOSE
--------------------------------------------------------------------------------

One purpose only: remove unlock delays on supported link shorteners and file hosts so you reach the destination faster. It does not collect personal data for ads, inject advertisements, or add unrelated tools.


--------------------------------------------------------------------------------
SCRIPTING PERMISSION
--------------------------------------------------------------------------------

Uses the "scripting" permission to run small helpers in the page context on supported flows (for example, main-world hooks or visibility helpers that some unlock pages require). This is only for completing those flows—not for analytics or advertising.


--------------------------------------------------------------------------------
STORAGE PERMISSION
--------------------------------------------------------------------------------

Uses "storage" (chrome.storage.local) only for short-lived progress during multi-step shortener chains (for example Cut4Money, arolinks, nitrolink, or shortxlinks-style flows). That data stays on your device, is not sent to us, and is not used for ads. There is no global on/off setting—the popup does not turn automation off.


--------------------------------------------------------------------------------
COOKIES PERMISSION
--------------------------------------------------------------------------------

Uses the "cookies" permission so the background worker can read a site-set cookie on certain prolink pages when the destination URL is stored only in an HttpOnly cookie. Content scripts cannot read HttpOnly cookies. Values are read locally to finish the redirect on those supported pages; they are not uploaded or used for ads. The extension does not set or delete cookies for this purpose.


--------------------------------------------------------------------------------
WEB NAVIGATION PERMISSION
--------------------------------------------------------------------------------

Uses "webNavigation" to catch supported navigations early enough for the flow to work—for example instant shortener hops (such as multiup mirrors or mediator landings) and early main-world injects on specific unlock hosts. It is not used to track general browsing. Destinations come from the site’s own responses or page flow, not from a hardcoded end URL we invent.


--------------------------------------------------------------------------------
HOST PERMISSION
--------------------------------------------------------------------------------

Declares broad host access ("<all_urls>") because supported pages and mediators span many domains and change over time, and the content script must be able to run when you land on them. Host matching and page checks still limit real work to supported flows; unrelated sites are not modified for this purpose. This access is not used to collect browsing history or serve ads.
