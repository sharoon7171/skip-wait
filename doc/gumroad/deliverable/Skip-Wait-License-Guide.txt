Skip Wait — License Guide
=========================

Thank you for purchasing a Skip Wait monthly license on Gumroad.

This download is your product pack from Gumroad. Your license key is
sent separately to the email address on your Gumroad receipt (usually
within a few hours of purchase).


1. Install
----------
1. Open the Chrome Web Store listing for Skip Wait:
   https://chromewebstore.google.com/detail/hdoecnlghjglmnjpnhaaeofcgocdgkhd
2. Click Add to Chrome.
3. Pin Skip Wait from the Extensions menu if you want quick access.


2. Activate
-----------
1. Open the Skip Wait popup from the toolbar.
2. Paste your license key (format: SW-XXXX-XXXX-XXXX-XXXX).
3. Click Activate license.
4. Open a supported short link or delay page as usual.


3. What the license includes
----------------------------
- Bypass or automate waits on supported link shorteners, safelinks, and file hosts
- Instant redirect when the site allows it
- Automated continue / unlock steps when a full skip is not possible
- Refresh in the popup to pull the latest supported domains (no reinstall)


4. Supported sites
------------------
Live list:
https://skip-wait-website.vercel.app/sites

If a page fails, reply to your license email with the page URL.


5. License rules
----------------
- One device per key
- Monthly license (renew by purchasing again when it expires)
- Keys are checked live with the license server before each bypass
