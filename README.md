## What it does

- **Skip countdown timers** - Bypass countdown and delay timers on download and link pages.
- **Bypass link shorteners** - Get past short-link and redirect pages to the final URL.
- **Skip waiting pages** - Avoid “please wait” and “click to continue” screens.
- **Instant redirect** - When possible, you’re sent straight to the target URL.
- **Automation when needed** - On sites where full bypass isn’t possible, Skip Wait automates waiting and clicking so you still save time.

## How it works

1. Install Skip Wait from the Chrome Web Store (use the link above).
2. Activate a $1.50 per month license in the popup.
3. Browse as usual. When you land on a supported waiting page, countdown page, or short-link page, Skip Wait runs automatically.
4. You’re either redirected to the final URL or the extension automates the wait/click so you reach your destination faster. No configuration needed for supported sites.
